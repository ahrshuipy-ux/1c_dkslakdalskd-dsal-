# Восстановление из main.exe

Программа собрана PyInstaller с Python 3.14. При извлечении байткод только читался.

- `source/` содержит пять восстановленных файлов: `main.py`, `app/__init__.py`, `app/settings.py`, `app/gui.py` и `app/excel_utils.py`. Скомпилированные инструкции, имена и константы совпадают с извлечёнными.
- `bytecode/` содержит 16 файлов .pyc, включая все модули пакета app. Для чтения этого формата нужен Python 3.14.
- `disassembly/` содержит листинги инструкций для всех 16 файлов.
- `modules.tsv` сопоставляет имена модулей с путями в собранной программе.

Исходный текст остальных 11 модулей, комментарии и форматирование отсутствуют. Сторонние зависимости в этот архив не включены. Запуск приложения не проверялся.
