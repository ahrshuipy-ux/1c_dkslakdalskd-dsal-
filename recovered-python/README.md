# Восстановление из main.exe

Программа собрана PyInstaller с Python 3.14.

- `source/` содержит все 16 восстановленных файлов Python. При повторной компиляции совпали инструкции, имена, константы и таблицы исключений, включая вложенные функции.
- `bytecode/` содержит все 16 файлов `.pyc`. Они побайтово совпадают со свежим извлечением из `main.exe`.
- `disassembly/` содержит листинги инструкций для всех файлов.
- `modules.tsv` сопоставляет имена модулей с путями в собранной программе.

Проверены импорт приложения из исходников, расчёт прогноза, отчёт сравнения и сводная статистика. На пробных книгах Excel результаты совпали с оригинальным байткодом. Графический интерфейс не проверялся.

Текст восстановлен по байткоду. Исходные комментарии и форматирование в сборке отсутствуют. Для запуска исходников нужны Python 3.14, Tkinter и openpyxl.
