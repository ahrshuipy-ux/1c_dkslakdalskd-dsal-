# Восстановление из main.exe

Программа собрана PyInstaller с Python 3.14. При извлечении байткод только читался.

- `source/` содержит пятнадцать восстановленных файлов. При проверке после компиляции совпали инструкции, имена, константы и таблицы исключений, включая вложенные функции.
- `bytecode/` содержит 16 файлов .pyc, включая все модули пакета app. Для чтения этого формата нужен Python 3.14.
- `disassembly/` содержит листинги инструкций для всех 16 файлов.
- `modules.tsv` сопоставляет имена модулей с путями в собранной программе.

Исходный текст модуля forecast, комментарии и форматирование отсутствуют. Сторонние зависимости в этот архив не включены. Запуск приложения не проверялся.
